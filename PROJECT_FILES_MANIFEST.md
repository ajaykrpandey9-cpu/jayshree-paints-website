## 💡 TIPS FOR EDITING FILES

### Using VS Code (Recommended)
```
1. Download VS Code (free)
2. File → Open Folder → jayshree-paints-website
3. Double-click any file to edit
4. Install "Live Server" extension
5. Right-click index.html → "Open with Live Server"
6. Auto-refresh on every save!
```

### Using Simple Text Editor
- Windows: Notepad, Notepad++
- Mac: TextEdit, Sublime Text
- Linux: gedit, nano, vim
- Web: VS Code Online (free)

### Common Edit Patterns

**Find & Replace text:**
- Mac: Command+H
- Windows/Linux: Ctrl+H
- In browser: Ctrl+F (search only)

**Edit HTML:**
- Use your text editor
- Save file
- Refresh browser

**Edit CSS:**
- Change `:root` variables for colors
- Save file
- Refresh browser

**Edit JavaScript:**
- Modify `productsData` array
- Modify `reviewsData` array
- Save file
- Refresh browser
